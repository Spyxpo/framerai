# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `stable` branch. Older
snapshots are not maintained. Please upgrade to the latest version before
reporting an issue.

| Branch | Supported |
|--------|-----------|
| stable | Yes |
| beta | Best effort |
| dev | No |

## Reporting a vulnerability

Do not open a public issue for security problems.

Report vulnerabilities privately through GitHub Security Advisories:

1. Go to the [Security tab](https://github.com/Spyxpo/framerai/security/advisories/new).
2. Provide a clear description, affected component, reproduction steps, and impact.

If you cannot use GitHub advisories, email security@spyxpo.com with the same
details.

## What to include

- The affected component (model, backend, or website).
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Any suggested remediation.

## Response process

- We aim to acknowledge new reports within 5 business days.
- We will confirm the issue and determine its severity.
- We will work on a fix and coordinate a disclosure timeline with you.
- We will credit reporters in the release notes unless anonymity is requested.

Please act in good faith. Avoid privacy violations, data destruction, and
service disruption while researching.
